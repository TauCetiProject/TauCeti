# Website and blog

The website is generated by Verso. Run `lake build` and
`lake exe web --output _out` from this directory. The front page also requires the
checked maths examples; see `.github/workflows/pages.yml` for their build setup.

The header shows **Blog** only when at least one published post is registered.
The `/blog/` index and each post use the existing site theme. Drafts are excluded
from the generated site, including archives and category lists.

To add a post:

1. Create `Site/Blog/FirstPost.lean`, following this format:

   ```lean
   import VersoBlog

   open Verso Genre Blog

   #doc (Post) "Your post title" =>

   %%%
   authors := ["Author Name"]
   date := {year := 2026, month := 10, day := 28}
   %%%

   Your post text, with **formatting**, [links](https://example.com), and sections.
   ```

2. Import `Site.Blog.FirstPost` in `Site/Blog.lean` and add it to `posts`:

   ```lean
   def posts : Array BlogPost := #[
     {id := %docName Site.Blog.FirstPost, contents := %doc Site.Blog.FirstPost}
   ]
   ```

   Keep posts newest first. The date and title determine the URL, for example
   `/blog/2026-10-28-your-post-title/`. Set `draft := true` in the metadata to
   withhold a registered post from publication. Remove it or set it to `false`
   when ready to publish.

Run `python3 tests/test_blog.py` from this directory to build fixture sites and
check empty and draft-only blogs, published navigation, archives, category pages,
post metadata, and nested links and assets. These tests use the pinned website
toolchain and Verso dependencies; they do not build Tau Ceti or Mathlib.
